# Codex 계획 검토자 등록

`.codex/agents/plan-reviewer.toml`은 읽기 전용 등록 설정이다. 모델·추론 설정은 상속한다. 역할의 정본은 `agents/plan-reviewer.md`, 상세 정책의 정본은 `rules/governance/planning.md`다.

개인 등록은 `~/.codex/agents/plan-reviewer.toml`에서 이 레포의 TOML로 심볼릭 링크를 연결한다. 대상 코드 레포에 파일을 추가하지 않는다. 같은 이름의 기존 설정은 덮어쓰지 않는다. 이 하네스 레포에서는 프로젝트 등록으로도 발견될 수 있다.

## 호출 자료

새 에이전트 맥락에서 `plan_reviewer`를 선택하고 다음 자료를 명시적으로 전달한다.

- `harness_root`: 이 하네스 체크아웃의 절대 경로.
- 요구사항·확정 제약·미결 질문과 대상 계획 ID·버전.
- 대상 레포 `.harness/plans/`의 전체 계획 위치, 이전 버전과 무효화·재검토 근거.
- 대상 코드 레포, 브랜치·커밋과 관련 미커밋 변경.

전체 대화를 상속하기보다 필요한 원본을 전달한다. 검토자는 다른 검토자를 호출하지 않으며 주 세션이 결과를 처리한다.

등록 후 새 세션에서 역할이 발견되는지 확인한다. 현재 세션에 즉시 반영된다고 가정하지 않는다. 발견되지 않으면 새 에이전트에 정본 경로를 전달하되 등록 역할을 사용했다고 보고하지 않는다.

레포 이동·새 환경 설치 시 개인 링크를 다시 연결해야 한다. 일반 설치 자동화는 아직 구현하지 않았다. 등록은 역할 발견 설정이며 자동 호출을 강제하는 훅은 아니다.

[OpenAI 공식 Subagents 문서](https://learn.chatgpt.com/docs/agent-configuration/subagents)의 개인·프로젝트 TOML 형식을 사용한다.
