Human Bottleneck — Workflow Harness v0.2.1 릴리스입니다.

- P(Plan)를 사용자가 변경 방향을 검토하는 주된 문서로 명확히 했습니다. 하위 T(Task)를 모두 읽지 않아도 변경 목적, 주요 동작과 구조, 설계 선택과 이유, 영향과 위험, 단계별 결과와 완료 판단 방법을 이해할 수 있게 작성합니다.
- T는 파일·함수, 세부 인터페이스와 호출 순서, 구현 절차와 검사 방법을 구체화합니다. 추가 도구 설치, 호환성 변경, 데이터 이관과 복구처럼 사용자 판단에 영향을 주는 기술 조건은 P에도 설명합니다. 독립 T는 판단에 필요한 설명을 자체적으로 담습니다.
- 고정 목차 대신 띄어쓰기, 완결된 문장, 주제별 문단 구분 등 가독성 기준을 추가했습니다. 과도한 압축이나 약어·조건 나열로 설명을 대신하지 않도록 하고, 계획 검토자도 이 기준을 확인합니다.

설치 인터페이스와 Windows/macOS 지원 범위는 v0.2.0과 같습니다. Python 3.9 이상이 필요하며 자산은 install.sh, install.ps1, 버전 고정 tar.gz 패키지, SHA256SUMS입니다. 업데이트는 기존 도구 선택과 개인 설정을 보존하며 Codex·Claude 앱 자체의 버전은 바꾸지 않습니다. 설치와 업데이트 방법은 README와 docs/installation.md를 참고하세요.

업데이트 후 새 Codex/Claude Code 세션에서 새 공통 규칙과 검토자 기준을 확인하세요. 실제 새 세션 로딩과 계획서 작성 효과는 설치 파일 검증과 별도로 확인해야 합니다. Linux·WSL은 지원 범위 밖입니다.
